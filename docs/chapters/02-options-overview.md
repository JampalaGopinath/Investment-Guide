# Chapter 2 — Options Overview

!!! note "Side heading: Shortlist"
    Four common "safe" options match this scenario. Each has a different trade-off between return, liquidity, and effort.

## Comparison table

| Scheme | Lock-in | Interest Type | Best For |
|--------|---------|---------------|----------|
| **SBI FD** (Senior Citizen) | None (early withdrawal allowed) | Compounding | Flexibility |
| **NSC** (National Savings Certificate) | 5 years | Auto-compounding | Locked growth |
| **Post Office TD** (Time Deposit) | None (early withdrawal allowed) | Annual payout | Moderate return |
| **SCSS** | 5 years (partial after 1 year) | Quarterly payout | Regular income |

## Quick decision guide

!!! note "Side heading: Simple rule"
    If your **top priority is maximum corpus at maturity with zero effort** → choose NSC.  
    If you also need **flexibility to access funds** → pair NSC with SBI FD.

| Priority | Best scheme |
|----------|-------------|
| Maximum growth, zero effort | NSC |
| Flexibility + decent growth | SBI FD |
| Annual cash flow from interest | Post Office TD |
| Regular quarterly income | SCSS |
