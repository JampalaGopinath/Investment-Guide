# Chapter 14 — Final Maturity Comparison

!!! note "Side heading: Read this table first"
    This chapter shows the value at maturity for ₹1,00,000 invested today in each scheme, along with a summary of compounding behaviour and required effort.

## Comparison — ₹1,00,000 invested in March 2026

| Scheme | 5-Year Value | 10-Year Value* | Compounding | Effort |
|--------|--------------|----------------|-------------|--------|
| **NSC (7.7%)** | ₹1,44,900 | ₹2,10,000 | Automatic | None |
| **SBI FD (7.05%)** | ₹1,41,800 | ₹1,97,600 | Automatic | Low |
| **PO TD (7.5%)** | ₹1,37,500 | ₹1,95,000\*\* | Manual | High |
| **SCSS (8.2%)** | ₹1,41,000 | ₹1,90,000\*\*\* | None | Very High |

\* Assumes reinvestment at maturity at comparable rates  
\*\* Only if interest is reinvested annually — otherwise significantly lower  
\*\*\* Assumes perfect quarterly reinvestment discipline throughout

!!! note "Side heading: The key insight"
    NSC gives the **highest 5-year value** despite not having the highest nominal rate, because it compounds automatically. SCSS has the highest nominal rate (8.2%) but the lowest final value because interest exits every quarter.

## Conclusion from this comparison

!!! note "Side heading: NSC wins on growth, SBI FD wins on flexibility"
    For **pure corpus maximisation** → NSC.  
    For **flexibility + reasonable growth** → SBI FD.  
    For **regular income** (not corpus) → SCSS.  
    For **flexible moderate income** → PO TD (but requires reinvestment discipline).
